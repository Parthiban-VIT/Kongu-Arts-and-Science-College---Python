# Python Practical Lab – Streamlit App

Interactive Streamlit application for 10 undergraduate Mathematics Python practical programmes.

## Programmes
1. Sum and Average
2. Armstrong Numbers
3. Matrix Multiplication
4. Variance and Standard Deviation
5. Fibonacci Sequence
6. Factorial
7. Count Vowels
8. Pie Chart
9. Student Grade
10. Quadratic Equation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy from GitHub

1. Upload `app.py` and `requirements.txt` to a GitHub repository.
2. Open Streamlit Community Cloud.
3. Sign in with GitHub.
4. Create a new app.
5. Select the repository and `main` branch.
6. Set the main file to `app.py`.
7. Deploy.

The app provides:
- Aim and concept for every programme
- Formula/key idea
- Interactive inputs
- Live outputs
- Graphs for suitable programmes
- Full Python source code
- Download button for each programme
